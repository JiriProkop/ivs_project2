Installation
------
To install the program using the terminal, cd into the directory with the package and run this command:
```console
$ sudo dpkg -i calc-1.0.deb
```
Or you can use the Ubuntu Software Center for that: Simpy left click the package, wait for Software Center to open and click Install.

Uninstallation
------
To uinstall the program, you can use the Calc Uninstaller, just open, click the Yes button and enter the root password.
Alternatively, you can run this command in the terminal:
```console
$ sudo dpkg -r calc
```
